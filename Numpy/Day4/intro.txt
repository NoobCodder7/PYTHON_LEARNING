# 📘 NumPy Day 4 – Array Operations & Broadcasting

## 📖 Overview

Welcome to **Day 4** of the NumPy roadmap!

After learning how to create arrays, inspect their properties, and access data using indexing and slicing, it's time to perform **mathematical operations** on arrays.

One of NumPy's biggest advantages is its ability to perform operations on entire arrays without using loops. This feature makes NumPy incredibly fast and efficient, making it the preferred choice for Data Analysis, Machine Learning, Artificial Intelligence, and Scientific Computing.

In this lesson, you'll learn how to perform arithmetic operations, comparison operations, use Universal Functions (UFuncs), understand broadcasting, and apply vectorized computations.

---

# 🎯 Learning Objectives

By the end of this lesson, you will be able to:

- Perform arithmetic operations on NumPy arrays.
- Apply scalar operations to arrays.
- Compare array elements using comparison operators.
- Use NumPy Universal Functions (UFuncs).
- Perform aggregate calculations.
- Work with row-wise and column-wise operations using `axis`.
- Understand broadcasting.
- Write efficient vectorized code without loops.

---

# 📚 Topics Covered

## 1. Arithmetic Operations

Perform element-wise operations on arrays:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Floor Division (`//`)
- Modulus (`%`)
- Exponent (`**`)

---

## 2. Scalar Operations

Apply a single value to every element of an array.

Examples:

- Add a number
- Subtract a number
- Multiply by a number
- Divide by a number

---

## 3. Comparison Operations

Compare array elements using:

- Greater than (`>`)
- Less than (`<`)
- Greater than or equal to (`>=`)
- Less than or equal to (`<=`)
- Equal to (`==`)
- Not equal to (`!=`)

These operations return Boolean arrays.

---

## 4. Universal Functions (UFuncs)

Learn NumPy's built-in mathematical functions:

- `np.abs()`
- `np.sqrt()`
- `np.power()`
- `np.exp()`
- `np.log()`
- `np.sin()`
- `np.cos()`
- `np.tan()`

---

## 5. Aggregate Functions

Summarize data using:

- `np.sum()`
- `np.mean()`
- `np.min()`
- `np.max()`
- `np.prod()`
- `np.cumsum()`
- `np.cumprod()`

---

## 6. Axis Operations

Perform operations:

- Row-wise (`axis=1`)
- Column-wise (`axis=0`)

Examples:

- Sum of rows
- Sum of columns
- Mean of rows
- Mean of columns

---

## 7. Broadcasting

Learn how NumPy automatically performs operations on arrays with compatible shapes.

Examples:

- Add a scalar to a matrix
- Add two arrays of different shapes
- Multiply arrays using broadcasting

---

## 8. Vectorization

Replace loops with NumPy operations for:

- Faster execution
- Cleaner code
- Better memory efficiency

# 🧠 Key Concepts Learned

- NumPy performs element-wise arithmetic operations.
- Scalar operations affect every element in an array.
- Comparison operators return Boolean arrays.
- Universal Functions (UFuncs) perform mathematical computations efficiently.
- Aggregate functions summarize data quickly.
- `axis=0` performs operations column-wise.
- `axis=1` performs operations row-wise.
- Broadcasting allows operations on arrays with compatible shapes.
- Vectorization eliminates the need for loops and significantly improves performance.
