# 📌 Functions and Properties Learned

| Property / Function | Purpose |
|---------------------|---------|
| `shape` | Returns array dimensions |
| `size` | Returns total elements |
| `ndim` | Returns number of dimensions |
| `dtype` | Returns datatype |
| `itemsize` | Returns memory used by one element |
| `nbytes` | Returns total memory used |
| `astype()` | Converts datatype |
| `copy()` | Creates an independent copy |
| `view()` | Creates a shared copy |

---

# 🧠 Key Concepts Learned

- Every NumPy array has properties that describe its structure.
- `shape` tells the dimensions of an array.
- `size` gives the total number of elements.
- `ndim` tells how many dimensions an array has.
- `dtype` identifies the datatype of the array.
- `itemsize` tells how much memory one element occupies.
- `nbytes` calculates the total memory used.
- `astype()` changes the datatype of an array.
- `copy()` creates a completely separate array.
- `view()` shares the same memory as the original array.

---

# 🔍 Difference Between copy() and view()

| copy() | view() |
|----------|---------|
| Creates a new array | Shares the original array |
| Uses more memory | Uses less memory |
| Changes don't affect original | Changes affect original |
| Independent | Dependent |
