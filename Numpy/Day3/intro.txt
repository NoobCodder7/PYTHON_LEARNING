# 📘 NumPy Day 3 – Indexing & Slicing

## 📖 Overview

Welcome to **Day 3** of the NumPy roadmap!

After learning how to create arrays and understand their properties, today's focus is on **accessing and extracting data** from NumPy arrays.

Indexing and slicing are among the most important NumPy concepts because real-world datasets often contain thousands or even millions of records. Instead of working with an entire dataset, you'll learn how to access only the data you need.

These concepts are used daily in Data Analysis, Machine Learning, and Artificial Intelligence.

---

# 🎯 Learning Objectives

By the end of this lesson, you will be able to:

- Access individual elements using indexing.
- Use positive and negative indexing.
- Extract data using slicing.
- Work with 2D and 3D array indexing.
- Filter data using Boolean Indexing.
- Select multiple elements using Fancy Indexing.
- Retrieve specific rows and columns from datasets.

# 🧠 Key Concepts Learned

- NumPy indexing starts from **0**.
- Negative indexing starts from **-1**.
- Slicing follows the format `start:stop:step`.
- The stop index is **not included**.
- Boolean indexing returns only values that satisfy a condition.
- Fancy indexing allows selecting multiple elements simultaneously.
- Indexing and slicing make data extraction fast and efficient.
