# 📘 NumPy Day 1 – Introduction to NumPy

## 📖 Overview

Welcome to **Day 1** of the NumPy learning roadmap!

Today, you'll learn the fundamentals of NumPy, the most important Python library for numerical computing. NumPy is the foundation for Data Analysis, Machine Learning, Artificial Intelligence, Scientific Computing, and many other Python libraries.

# 📌 Functions Learned

| Function | Purpose |
|----------|---------|
| `np.array()` | Create an array from a list or tuple |
| `np.zeros()` | Create an array filled with zeros |
| `np.ones()` | Create an array filled with ones |
| `np.empty()` | Create an uninitialized array |
| `np.arange()` | Create a sequence of numbers |
| `np.linspace()` | Create evenly spaced numbers |
| `np.eye()` | Create an identity matrix |
| `np.identity()` | Create an identity matrix |
| `np.full()` | Fill an array with a specified value |

---

# 🧠 Key Concepts Learned

- NumPy stands for **Numerical Python**.
- NumPy stores data in **ndarray** objects.
- Arrays are faster than Python lists.
- Arrays consume less memory.
- Mathematical operations are easier with NumPy.
- NumPy is the backbone of Data Science and Machine Learning.
